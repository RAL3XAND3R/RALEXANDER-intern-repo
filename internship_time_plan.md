## Phase 1: Onboarding (Weeks 1–6)

During the onboarding period, I will focus on completing the assigned onboarding issues, setting up my development environment, and getting familiar with the team's workflow and development practices.

**Week 1 (Aug 17 – Aug 23):** Learn about the company and the product, review the main policies, and get familiar with the basic Git workflow and Milestones 0 and 1.

**Week 2 (Aug 24 – Aug 30):** Continue with Git, including branching, handling merge conflicts, and learning more about clean code.

**Week 3 (Aug 31 – Sep 06):** Work on clean code, error handling, refactoring, and identifying common code issues.

**Week 4 (Sep 07 – Sep 13):** Learn the basics of testing, including unit testing with Jest and mocking API calls.

**Week 5 (Sep 14 – Sep 20):** Get familiar with the NestJS backend structure, API patterns, and database integration.

**Week 6 (Sep 21 – Sep 27):** Finish the remaining onboarding work, review what I have learned, and start preparing to work on tickets in the main codebase.
