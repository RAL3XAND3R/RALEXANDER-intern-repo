# Terminal Knowledge

## Which terminal client did you choose? Why?

I chose to use PowerShell through the integrated terminal in VS Code.

I chose it because I already use VS Code for development, so having the terminal inside the same application makes things more convenient. I can work on my code and run commands without having to open a separate terminal window.

I have been using the terminal for things like Git, navigating between project folders, and running development commands, so I wanted to become more comfortable using it.

## What customizations did you make?

I did not make any major customizations to PowerShell. I kept the default setup because it already works well for what I need.

For now, I prefer keeping the terminal simple instead of adding themes, plugins, or aliases that I don't really need yet.

## What was the most useful command you learned today?

The commands I found most useful were `cd`, `cd ..`, `ls`, `dir`, and `mkdir`.

`cd` allows me to move to a specific folder. For example:

```powershell
cd "C:\Focus bear"
```

`cd ..` allows me to go back to the parent folder. I use this quite often when moving between different project directories.

I also learned that PowerShell supports commands such as `ls` and `dir` for listing files and folders. I was a little confused about this at first because I had seen these commands in Linux before, but PowerShell also supports them.

For example:

```powershell
ls
```

or:

```powershell
dir
```

Both allow me to see the files and folders in my current location.

`mkdir` can be used to create a new folder, which is also useful when setting up new projects or organizing files.

## What I learned

I learned that being comfortable with the command line makes it easier to move around my projects and manage files without always relying on the graphical interface.

I also learned that PowerShell is not a Linux terminal, even though some commands such as `ls`, `cd`, and `mkdir` work in both environments. This was useful for me because I had started mixing up some Linux commands with PowerShell commands.

Since I already use the terminal regularly for Git and development, becoming more familiar with these basic commands should make my daily workflow faster and easier.
