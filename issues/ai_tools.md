# AI Tools

## Which AI tools did you try?

I tried ChatGPT as an AI coding assistant.

I have already been using ChatGPT for development and university projects, especially when I need help understanding code, debugging problems, or learning something that I am not familiar with.

## What did I use AI for?

I experimented with AI in different parts of the development process.

First, I used it to generate code snippets. I could describe what I needed and ask for an example implementation. This was useful as a starting point, but I still needed to review the code and make sure it actually fit the project.

I also used AI for debugging. When I had an error, I could provide the error message and the relevant code and ask what could be causing the problem. This helped me find possible solutions faster instead of trying to figure everything out from the beginning.

Another thing I use AI for is explaining concepts that I am learning. For example, when I come across something in NestJS or another technology that I don't understand, I can ask for an explanation and then ask more questions if something is still unclear.

## What worked well?

The most useful part for me was getting explanations and debugging help.

AI can quickly look at a piece of code and explain what it is doing in simpler terms. This is especially helpful when I am learning a new framework or working with code that I have not seen before.

Debugging is also easier because I can describe the problem and get several possible causes to investigate. This can save time and help me approach the problem from a different perspective.

Generating code is useful too, especially for repetitive tasks or when I need an example of how something should be structured.

## What didn't work well?

One limitation is that AI does not always have the complete context of a project. If I only provide part of the code, it can make assumptions about the rest of the application that are not necessarily correct.

Sometimes it can also suggest code that looks correct but does not fit the way the project is structured. Because of this, I don't think AI should be used by simply copying everything it generates.

I still need to understand the code, test the solution, and decide whether the suggestion actually makes sense for the project.

## When do I think AI is most useful for coding?

I think AI is most useful when I am stuck on a problem, learning something new, or need to understand code that I did not write myself.

It is also useful for repetitive tasks and for getting a starting point when I know what I want to accomplish but I am not sure how to implement it.

For me, the biggest benefit is that I can use AI as an assistant while still doing the actual thinking and decision-making myself. It helps me get unstuck and learn faster, but I still need to understand and verify the result.
