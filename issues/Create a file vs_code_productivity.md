# VS Code Productivity

## Navigation

### Ctrl + P

`Ctrl + P` opens the Quick Open menu. I can start typing the name of a file and VS Code will find it for me. This is useful when working on bigger projects because I don't have to manually search through all the folders.

### Ctrl + G

`Ctrl + G` lets me jump directly to a specific line in a file. For example, if I need to go to line 150, I can use this shortcut instead of scrolling through the file.

### Ctrl + Shift + O

`Ctrl + Shift + O` shows the symbols in the current file, such as functions, classes, and methods. I can use it to quickly find a specific function without searching through the whole file.

---

## Editing

### Ctrl + D

`Ctrl + D` selects the next occurrence of the text I currently have selected. This is useful when I want to change the same variable or piece of text in several places at the same time.

### Alt + Click

`Alt + Click` adds another cursor where I click. This allows me to edit multiple different places in a file at the same time.

### Ctrl + Alt + Up / Down

`Ctrl + Alt + Up` or `Ctrl + Alt + Down` adds another cursor above or below the current cursor. This is one of the multiple cursor shortcuts that I think is especially useful because I can write or edit several lines simultaneously.

### Shift + Alt + Up / Down

`Shift + Alt + Up` or `Shift + Alt + Down` duplicates the current line above or below. I can use this when I need to create similar lines without copying and pasting manually.

---

## Debugging

### F5

`F5` starts the debugger. This is useful when I need to run my application and investigate how the code behaves instead of just running it normally.

### F9

`F9` adds or removes a breakpoint on the current line. Breakpoints are useful because they allow me to stop the program at a specific point and inspect what is happening.

### F10

`F10` executes the next line while debugging. This allows me to go through the code step by step and understand what each line is doing.

---

## Terminal Commands

### Ctrl + `

`Ctrl + backtick` opens or closes the integrated terminal in VS Code. I use this to run commands without having to open another terminal window.

## My Most Useful Shortcuts

The shortcuts I think I will use the most in my daily work are `Ctrl + P`, `Ctrl + D`, the multiple cursor shortcuts, and `Ctrl + backtick`.

`Ctrl + P` will be useful because I often work with projects that contain many folders and files, so being able to quickly find a file saves time.

I also think multiple cursors will be very useful when editing code. Instead of changing the same thing one line at a time, I can edit several places simultaneously.

`Ctrl + backtick` is also useful because I can quickly switch between my code and the terminal without leaving VS Code.

For debugging, `F9` and `F10` will help me understand what is happening inside my applications when something is not working correctly.

## How Keyboard Shortcuts Improve Productivity

Keyboard shortcuts make development faster because they reduce the amount of time I spend clicking through menus or searching for options.

They also help me stay focused on the code. For example, instead of using the mouse to find a file, I can press `Ctrl + P` and open it immediately. Multiple cursors can also save a lot of time when I need to make the same change in several places.

I think the biggest benefit is that shortcuts make common actions become almost automatic. The more I use them, the less I have to stop what I am doing to look for a button or menu option. This can make my daily development workflow faster and more comfortable.
