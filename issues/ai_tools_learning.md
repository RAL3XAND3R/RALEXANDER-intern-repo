# AI Tools Learning

## Which tool did I use?

I used Antigravity as my AI coding tool.

I already had experience using it for university assignments, so I chose it because I was already familiar with it and wanted to explore how useful it could be as part of a normal development workflow.

## What did I use it for?

I mainly used Antigravity for two tasks.

The first one was understanding existing code. When I found code that I did not fully understand, I could ask Antigravity to explain what the code was doing and why certain parts were written that way. This was especially useful when working with code that had multiple functions or concepts that I was not familiar with yet.

The second task was debugging. When I had an error or something that was not working correctly, I could give Antigravity the code and the error and ask it to find the problem and suggest a fix.

For example, I could ask it to explain why something was failing and then propose a change to the code.

## What did it help with?

Antigravity was especially useful for explaining things in a simpler way when I did not understand something immediately.

It also helped me find possible causes of errors faster. Instead of spending a long time trying to understand where a problem could be, I could use the AI to get some possible explanations and then check them myself.

I think it is also useful for learning because I can ask follow-up questions about the explanation instead of only getting a solution.

## What did it struggle with?

One thing I noticed is that AI does not always understand the entire context of a project. If I only provide a small part of the code, it can sometimes make assumptions about how the rest of the application works.

It can also suggest a solution that looks correct but is not necessarily the best solution for the project. Because of this, I think it is important to understand and review the suggested changes instead of blindly copying them.

## What I learned

The main thing I learned is that AI coding tools are useful as a development assistant, but they should not replace understanding the code.

I can use Antigravity to explain code, find possible bugs, and suggest solutions, but I still need to understand what it is changing and verify that the solution actually works.

Using AI this way can save time while still allowing me to learn from the problems I am solving.
