# Git Knowledge

## Have you used Git before?

Yes, I had used Git before for university projects and other development work, but during these past days I have been using it more often and getting more comfortable with the commands.

I have used Git to create branches, make commits, push changes to GitHub, and work with pull requests. I have also learned how important it is to pay attention to which branch I am currently working on before making a commit or pushing changes.

## Which Git client did you choose? Why?

I decided to use the Git terminal integrated into VS Code.

I prefer using the terminal because I can see exactly which Git commands I am running and understand what each command is doing. Since I am already working in VS Code for development, having the terminal there makes it convenient to manage Git without switching to another application.

## What was the most interesting thing you learned about Git today?

One of the most interesting things I learned was how Git keeps track of the changes in my project and lets me see what is happening before I commit anything.

For example, I learned how to check the current state of my repository and see which files have been modified, deleted, or are still untracked. I can then decide which changes I want to add to the next commit instead of committing everything without checking it first.

I also learned that I can add specific files to the staging area or remove them from it before making a commit. This helped me understand that a commit does not necessarily have to contain every change I have made.

After working with branches and commits these past days, I also realized that Git is not only about uploading files to GitHub. It gives me control over the history of my project and lets me choose which changes I want to save together.
